## Overview
Managing stock manually often leads to human errors and missing data. The **Inventory Management System** provides a structured digital workflow to record, monitor, and manage inventory items effectively. Built using clean Python architecture, it ensures reliable stock management.

---

## Key Features
- **Item Categorization & Tracking**: Easily record product IDs, names, quantities, and pricing.
- **Stock Updates**: Dynamic capabilities to add, modify, or remove stock counts in real time.
- **Data Consistency**: Ensures reliable record-keeping and prevents negative stock values.
- **Clean CLI Interface**: Simple, interactive, and intuitive menu-driven interaction.
